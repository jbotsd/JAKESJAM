# JAKESJAM Design Pack

This pack contains repo-ready Markdown files for the JAKESJAM game design and Codex-assisted implementation workflow.

## Files

- `AGENTS.md` — project instructions for Codex and contributors.
- `docs/game-design-document.md` — full GDD v0.1.
- `docs/codex-task-backlog.md` — implementation-ready task backlog.
- `docs/technical-design.md` — architecture summary.
- `docs/art-direction.md` — art/audio direction.
- `docs/changelog.md` — design changelog.

## Suggested Use

Copy these files into the root of the project repository, then start implementation from the backlog in order.
